A self-contained GTA6 meme generator built for make.fun's `gta6-meme-x-01` bounty. `build_meme.py` downloads make.fun's ghost mascot press asset, composes a 1080x1080 Vice-City-style sunset scene (gradient sky, lit-window skyline, banded sun) around the glowing mascot, and renders bold outlined caption text pitching make.fun with the play code `makefun-binder-balloon-hiker`. The resulting meme was posted on X and is referenced by `POST.json` for the bounty gate.
